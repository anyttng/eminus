# Eminus

A NeoForge mod that draws terrain far beyond the game's render distance. Eminus keeps a coarse, persistent copy of every chunk the client has seen and renders that copy as a far layer behind the game's own terrain, on both graphics APIs the game offers — OpenGL and Vulkan.

*Eminus* is Latin for "from afar".

## Versions

- Minecraft **26.2**
- NeoForge

## Status
